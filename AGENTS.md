Este repositorio contiene varios proyectos independientes:

- `spotify-app/`: aplicación Expo / React Native. Sigue sus instrucciones en `spotify-app/AGENTS.md`.
- `reccobeats-lab/`: programa Python de terminal. Consulta su README para ejecutarlo y probarlo.
- `ai-features-lab/`: laboratorio Java 21 para consultar Gemini directamente. Consulta su README; `./run.sh --help` compila sin realizar peticiones.

- `service lab/`: servicio Java 21 / Spring Boot con Maven y SQLite. Consulta su README y ejecuta `./mvnw verify` para comprobarlo.

Ejecuta los comandos desde la carpeta del proyecto correspondiente.
